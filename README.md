# Claude Code Skills

This repository is a collection of skills I have built over time, a living repository that I keep adding to. As the work progressed I came to see that other people need the same ideas I had put together, so I decided to share them. The skills here represent my workflow, the way I think and the tools I built for myself.

There are many skills on the internet and people publish them on GitHub. I am not claiming that mine are better than anyone else's. They are simply mine. If they are of value to you, then use them and change them, though I would ask one thing in return, which is that you tell me how you would change them. Open an issue, send me a message, tell me that you have a different need or ask me how I did something, so that together we can arrive at something better.

## Superpowers

Among all of these there is one skill I use so often that I cannot work without it, a skill called Superpowers. I recommend that you look into it and use it, because it helps with planning, gives clarity and shapes the way you approach your work. You can find it at [Superpowers](https://github.com/obra/superpowers).

## Why invest in skills

Beyond any single skill, I suggest that you invest real effort in understanding how skills are used, what you can do with them and how far you can take them. This is the essence of using large language models. In my view it matters more than autonomous agents do. A skill is knowledge captured and that captured knowledge is the most important part of working well with large language models, so this is worth your investment.

## What is here

Each skill lives in its own folder with its own documentation.

- [`anti-ai-writing`](anti-ai-writing): writing rules that remove the patterns marking text as machine generated
- [`deploy-skill`](deploy-skill): packages one of your skills and publishes it to your own GitHub repository
- [`marp-deck`](marp-deck): turns a note into a portable Marp presentation
- [`model-router`](model-router): classifies a task and routes it to the right model tier
- [`study-note`](study-note): processes a document into a standard study-note format
- [`youtube2article`](youtube2article): converts a YouTube video into a readable markdown article
